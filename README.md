# 47 Skin — Could this be right for your skin?

A speculative 47 Skin consideration-stage campaign email presented in a Gmail-inspired demonstration inbox. Not affiliated with or sent by 47 Skin.

## Local development

```bash
npm install
npm run dev
```

## Production / Vercel

```bash
npm run build
```

Import this directory into a GitHub repository, then import the repository in Vercel. Framework: **Vite**. Build: `npm run build`. Output: `dist`. Project name suggestion: `47skin-consideration-email`.

## Experience

The inbox opens by default. Only the 47 Skin email is openable. Back returns to inbox. Search and sidebar navigation are interactive. The “Explore the formula” CTA points to the 47 Skin product URL supplied in the earlier campaign brief.

## Artwork note

`editorial-real-skin.png` is a conceptual AI-generated portrait, not an actual customer or verified user. No synthetic product packaging is shown.
